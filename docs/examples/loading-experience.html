Responsive feedback patterns

Waiting, designed.

Loading feedback should describe what is happening, preserve context, and feel native to the product. Motion is a supporting signal, never a reason to delay useful content.

7

Motion families observed

The supplied study organizes rings, dots, fading circles, bouncing balls, time, signal strength, and task icons. This library turns those visual categories into product decisions.

Decision template

Specify the wait before drawing it.

A loading component is complete only when task scope, progress truth, status copy, timeout, error recovery, and reduced-motion behavior are documented.

01Scope

Page, region, control, or background task.

02Duration band

Expected and maximum wait, measured where possible.

03Progress truth

None, staged, or determinate from real work.

04Status language

Specific action, current stage, and user consequence.

05Recovery

Timeout, retry, cancel, and preserved input.

06Motion budget

Transform and opacity, reduced state, no forced delay.

All animations use CSS transforms or opacity. Status and progress remain available without motion, and the pause control is provided for this demonstration library.
