Three rules for calm movement.

Direction, continuity, and restraint make the interface feel responsive without replacing native scrolling.

DIRECTION

Enter from travel

Downward scrolling reveals from below. Upward scrolling reveals from above. Distance stays short enough to preserve context.

CONTINUITY

Keep object identity

FLIP-style motion is reserved for the same object changing position, not used as decoration between unrelated elements.

RESTRAINT

Finish before input

Ready content is never held for choreography. Interrupted animations settle in the correct final state.

02
